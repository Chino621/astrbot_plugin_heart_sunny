# 心晴助手 (HeartSunny)

(注:本插件由Deepseek和Gemini联合开发)

本项目为个人开发的开源公益项目。部分量表题目来源于公共网络学术资料，本插件不涉及任何商业用途。如果权利方认为该项目侵犯了您的权益，请通过 GitHub Issues或QQ 联系我，我会在第一时间下架并删除相关数据。

> “希望借助这个插件帮助到大家”

心晴助手是一款专为 AstrBot 设计的心理健康辅助插件。在海平面上升、世界喧嚣的时代，我们希望通过专业量表测评、情绪打卡与 AI 温情解读，为你提供一个安静、专业且温暖的心灵避风港。

---

## ✨ 功能特性

- **专业量表测评**：内置 12 种国际通用或临床标准的心理测评量表，涵盖抑郁、焦虑、自尊、孤独感等多个维度。
- **AI 温情解读**：测评结束后，AI 将化身为专业的心理咨询师，为你解析得分背后的意义，并提供具有建设性的心理建议。
- **情绪打卡与趋势**：记录每日心情分值，通过可视化图表（简易进度条）追踪你的情绪起伏。
- **心晴建议与作者语录**：每日随机推送温馨的心理小贴士，或聆听作者留下的感悟。
- **情绪急救箱**：内置 4-4-8 呼吸法、5-4-3-2-1 感官法等即时调节工具，并提供全国危机干预热线。

## 📋 指令说明

| 指令 | 说明 | 备注 |
| :--- | :--- | :--- |
| `/测评` | 开启心理测评菜单 | 仅限私聊使用 |
| `/打卡` | 记录今日心情 (1-10分) | 每天仅限一次有效记录 |
| `/心情` | 查看最近一周的心情趋势 | 统计过去 7 天的数据 |
| `/建议` | 获取随机心理健康小贴士 | 
| `/作者的话` | 聆听作者预设的语录 | 
| `/急救` | 获取情绪调节方法与危机热线 | 包含全国心理热线 |
| `/取消` | 随时终止当前的测评会话 | 清除当前对话状态 |

## ⚙️ 配置说明

在 AstrBot 管理面板中，你可以进行以下配置：

- **报告生成模式**：可选“大模型解读”或“纯评分”模式。
- **解读模型**：指定用于生成心理建议的 LLM Provider。
- **答题限时**：设置用户单题回复的超时时间。
- **自定义语录**：自由编辑“心理建议”与“作者的话”的内容库。

## 🚀 安装方法

1. 在 AstrBot 插件市场搜索 `astrbot_plugin_heart_sunny` 并安装。
2. 或者将本仓库克隆至 `data/plugins/` 目录下。
3. 重启 AstrBot 即可使用。

## ⚖️ 免责声明

1. **非临床诊断**：本插件提供的所有测评结果及 AI 解读内容仅供心理健康筛查参考，**不具备**临床医疗诊断效力。
2. **专业求助**：如果你感到严重的心理不适或有自伤倾向，请务必前往正规医院心理科就诊，或联系专业心理咨询机构。
3. **数据隐私**：测评数据仅保存在本地服务器，插件作者不会收集用户的任何隐私信息。
4. **AI 局限性**：AI 解读可能存在局限或偏差，请结合实际情况理性参考。
